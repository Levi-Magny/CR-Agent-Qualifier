# Agent Verification Procedure 001: `aq_monitor.c`

## 1. Purpose and scope

This procedure qualifies a code-review agent's review of
`src/aq_monitor.c`. It measures detection of requirement-boundary defects and
missing requirement traceability in the Air Quality Monitor module.

This file is the evaluator's private answer key. Do not provide it to the agent
under qualification.

## 2. Qualification inputs

Provide the candidate agent with `HLR.md`, `LLR.md`, `CODE_STANDARD.md`,
`src/aq_monitor.h`, and `src/aq_monitor.c`. Do not provide any `AVP-*.md`
file or hints about the number of seeded deviations.

## 3. Expected deviations

The agent may use different wording, but each row requires the stated defect
and at least one of the listed violated items.

| ID | Source location | Category | Violated items | Required finding | Minimum acceptable explanation |
|---|---|---|---|---|---|
| AVP-001-VC-01 | `src/aq_monitor.c:14` | Boundary validation | LLR-SENSOR-001 | The maximum AQI value is rejected. | `raw_value >= AQ_MAX_VALUE` rejects 500, although the valid range is inclusive through 500. |
| AVP-001-VC-02 | `src/aq_monitor.c:100` | Classification boundary | HLR-002, LLR-CLASSIFY-001 | AQI 150 receives the wrong classification. | The `aqi < AQ_SENSITIVE_GROUPS_MAX` condition excludes 150, which is then classified as `AQ_CLASS_UNHEALTHY` instead of `AQ_CLASS_UNHEALTHY_FOR_SENSITIVE_GROUPS`. |
| AVP-001-VC-03 | `src/aq_monitor.c:116` | Traceability and documentation | CS-003, CS-009, CS-011, CS-042 | The public alert function lacks required implementation documentation. | `aq_alert_required` has no Doxygen-style comment, requirement traceability, threshold constraint, or public-interface documentation. |

## 4. False-positive guard

| ID | Source location | Why it is compliant |
|---|---|---|
| FPG-001 | `src/aq_monitor.c:116-119` | The alert threshold comparison is correct: `average_aqi >= AQ_ALERT_THRESHOLD` implements LLR-ALERT-001. The missing documentation is a valid, separate finding. |

## 5. Scoring

Award one point for each correctly identified expected deviation. A finding
must cite a source location and a violated identifier, and it must explain the
correct root cause. Deduct one point for every false positive.

The maximum score is 3. The candidate passes this procedure only when it scores
**3/3** with **zero false positives**.
