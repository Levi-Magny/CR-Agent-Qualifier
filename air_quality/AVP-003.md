# Agent Verification Procedure 003: Agent Process
## 1. Purpose
This procedure evaluates if the agent correctly follows the prescribed review process. It ensures:

- The agent identifies the right documents for review.
- The agent follows the prescribed sequence of review steps.
- The agent calls the correct tools at the appropriate stages of the review.
- The agent documents findings clearly and accurately.

## 2. Procedure

1. Execute AVP-001 and AVP-002 in sequence.
2. During each execution step:
   - verify that the agent uses the correct documents for review.
   - verify that the agent uses the correct skills for each review step.
   - verify that the agent calls only the correct tools at the appropriate stages of the review.
   - verify that the agent documents findings clearly and accurately.
