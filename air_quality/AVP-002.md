# Agent Verification Procedure 002: `main.c`

## 1. Purpose and scope

This procedure qualifies a code-review agent's review of `src/main.c`. It
measures detection of integration, error-handling, and code-standard deviations
in the Air Quality Monitor application.

This file is the evaluator's private answer key. Do not provide it to the agent
under qualification.

## 2. Qualification inputs

Provide the candidate agent with `HLR.md`, `LLR.md`, `CODE_STANDARD.md`,
`src/aq_monitor.h`, and `src/main.c`. Do not provide any `AVP-*.md` file or
hints about the number of seeded deviations.

## 3. Expected deviations

The agent may use different wording, but each row requires the stated defect
and at least one of the listed violated items.

| ID | Source location | Category | Violated items | Required finding | Minimum acceptable explanation |
|---|---|---|---|---|---|
| AVP-002-VC-01 | `src/main.c:26-27` | Error handling and state update | HLR-001, HLR-004, LLR-FILTER-001, CS-004 | An invalid sensor reading updates the rolling filter. | The return status of `aq_sensor_read` is ignored and `aq_filter_add` executes even after `AQ_STATUS_RANGE_ERROR`; this adds a stale measurement. |
| AVP-002-VC-02 | `src/main.c:24` | Naming and constants | CS-002 | The polling-loop count is a magic number. | `5U` is a numeric literal other than 0 or 1 and must be represented by a named constant or macro. |
| AVP-002-VC-03 | `src/main.c:30-31` | Control flow | CS-001 | The true branch of the alert condition has no braces. | The statement `alert_active = true;` is the body of an `if` without `{` and `}`. |

## 4. False-positive guard

| ID | Source location | Why it is compliant |
|---|---|---|
| FPG-001 | `src/main.c:30` | `average > 150U` is equivalent to `average >= 151U` because `average` is an integer AQI value. |

## 5. Scoring

Award one point for each correctly identified expected deviation. A finding
must cite a source location and a violated identifier, and it must explain the
correct root cause. Deduct one point for every false positive.

The maximum score is 3. The candidate passes this procedure only when it scores
**3/3** with **zero false positives**.
